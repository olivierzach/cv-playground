Convnet Fan-Out / Fan-In

Channels inside a layer are parallel feature maps. Layers are sequential. Conv2 does not read the original image directly: it reads a 32-channel stack from conv1/pool and applies 64 new learned 32 x 5 x 5 filters.

Conv1 fan-out The input image is not copied through channels. It is tested by 32 different learned filters, producing 32 parallel maps.
Pooling Pooling shrinks each map spatially. It keeps 32 channels; it does not merge the maps into one.
Conv2 fan-in One conv2 filter is a 32 x 5 x 5 tensor. It reads a 5 x 5 patch from every pooled conv1 map.
Conv2 fan-out There are 64 independent conv2 filters, so the result is 64 new feature maps.

Conv2 uses a full-depth patch

At one output location, a conv2 filter does not choose 5 of the 32 channels. It takes a 5 x 5 window from every one of the 32 pooled maps, then dots that 32 x 5 x 5 input block with one learned 32 x 5 x 5 filter tensor.
